## 목적

이 문서는 메인 대시보드에서 발생하는 핵심 상호작용의 순서를 텍스트 시퀀스로 정리한다.

## 시퀀스 1: 날짜 선택

```text
사용자 -> 캘린더: 날짜 클릭
캘린더 -> 대시보드 상태: 선택 날짜 갱신
대시보드 상태 -> Today Board: 해당 날짜 일정 조회
Today Board -> 사용자: 선택 날짜의 일정 목록 표시
```

## 시퀀스 2: 일정 등록

```text
사용자 -> Quick Draft: 제목/시간/참여자 입력
Quick Draft -> 로컬 상태: 임시 일정 생성
로컬 상태 -> 캘린더: 새 일정 표시
로컬 상태 -> Today Board: 오늘 일정 목록 갱신
로컬 상태 -> Team Pulse: 부하 상태 재계산
```

## 시퀀스 3: 일정 충돌 확인

```text
시스템 -> 일정 계산기: 시간 중복 검사
일정 계산기 -> 대시보드 상태: conflict 플래그 반환
대시보드 상태 -> 캘린더: 경고 스타일 표시
대시보드 상태 -> 사용자: 충돌 안내 문구 표시
```

## 시퀀스 4: 집중 블록 보호

```text
사용자 -> Focus Blocks: 블록 확인
Focus Blocks -> 대시보드 상태: 집중 시간 세션 선택
대시보드 상태 -> 캘린더: 회의 겹침 경고 표시
대시보드 상태 -> 사용자: 대체 시간 제안 또는 경고 표시
```

## 비고

- 현재 단계는 프론트 상태 중심의 시퀀스다.
