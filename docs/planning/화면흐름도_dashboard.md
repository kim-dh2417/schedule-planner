## 흐름 개요
이번 구조에서는 월간 달력이 개인 업무관리의 중심이다. 사용자는 날짜를 선택해 일정과 업무일지를 함께 확인하고, 누적된 기록을 바탕으로 주간보고를 자동 정리한다.

## 화면 흐름

### 1. 앱 진입
- 사용자는 앱에 들어오면 달력을 가장 먼저 본다.
- 상단에는 오늘 일정, 업무일지 상태, 이번 주 기록 수 같은 최소 요약만 노출한다.
- 메인 목적은 달력에서 날짜를 선택해 기록을 이어가는 흐름을 만드는 것이다.

### 2. 날짜 선택
- 사용자가 날짜를 클릭한다.
- 우측 드로어나 오버레이 패널에서 해당 날짜의 일정 목록과 업무일지 요약이 함께 열린다.
- 선택된 날짜와 선택된 일정은 함께 강조된다.

### 3. 일정 추가 또는 수정
- 사용자가 `일정 추가` 또는 일정 상세의 수정 버튼을 누른다.
- 일정은 모달에서 작성한다.
- 알림 시점도 같은 모달에서 함께 설정한다.
- 저장이 완료되면 달력과 선택일 드로어가 즉시 갱신된다.

### 4. 업무일지 작성
- 사용자가 `업무일지 작성` 버튼을 누른다.
- 모달에서 한 줄 요약, 완료한 일, 이슈, 다음 액션을 입력한다.
- 저장 후 해당 날짜에 기록 완료 상태가 반영된다.

### 5. 주간보고 확인
- 사용자가 주간보고 버튼을 누른다.
- 선택한 날짜가 포함된 한 주의 기록을 자동으로 수집한다.
- 주간 핵심 요약, 일자별 기록, 이슈, 다음 액션을 모달에서 확인한다.

### 6. 알림 설정 확인
- 사용자가 알림 버튼을 누른다.
- 브라우저 권한 상태와 예정된 알림 목록을 확인한다.
- 필요하면 브라우저 알림 허용을 요청하거나 알림을 끈다.

## 모바일 흐름
- 모바일에서는 달력을 첫 화면으로 유지한다.
- 상세 정보는 하단 시트 또는 풀스크린 오버레이로 열린다.
- 일정 추가와 업무일지 작성은 고정 버튼 또는 상단 액션으로 진입한다.
