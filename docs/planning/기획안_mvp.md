## 제품 개요
Schedule Planner는 달력 위에 그날의 일정과 업무일지를 함께 기록하고, 누적된 기록을 바탕으로 주간보고를 자동 정리해주는 개인 업무관리 앱이다. 이번 MVP의 핵심은 달력을 단순 일정 조회 화면으로 두는 것이 아니라, `날짜 선택 -> 업무일지 기록 -> 주간보고 요약`으로 이어지는 개인 생산성 흐름을 만드는 것이다.

## 목표 사용자
- 매일 업무일지를 남겨야 하는 직장인
- 프로젝트 단위로 진행 상황을 스스로 정리해야 하는 프리랜서
- 주간보고나 회고를 수동으로 정리하는 데 시간을 쓰는 개인 사용자

## 해결하려는 문제
- 그날 한 일을 기록하는 습관이 없어 주간보고 작성 때 기억에 의존하게 된다.
- 일정과 실제 업무 기록이 분리돼 하루 흐름과 성과를 함께 보기 어렵다.
- 주간보고를 만들 때 메신저, 메모, 캘린더를 다시 뒤져야 한다.
- 중요한 일정은 미리 챙기고 싶지만 간단한 리마인드가 부족하다.

## 제품 방향
- 메인 화면은 월간 달력이 차지한다.
- 날짜를 클릭하면 선택일 일정과 업무일지는 드로어에서 함께 확인한다.
- 일정 추가와 수정은 모달에서 처리한다.
- 업무일지는 그날의 요약, 완료한 일, 이슈, 다음 액션을 기록하는 구조로 제공한다.
- 주간보고는 업무일지와 일정 기록을 바탕으로 자동 요약한다.
- 알림은 1차로 브라우저/PC 알림을 제공하고, 이메일 알림은 차기 범위로 둔다.

## MVP 범위
- 월간 달력 중심 홈
- 상단 KPI 요약 카드
- 선택일 일정 목록과 상세 드로어
- 일정 추가/수정 모달
- 날짜별 업무일지 작성 및 수정
- 주간보고 자동 요약 모달
- 브라우저/PC 일정 알림
- 일정 삭제와 충돌 표시

## 추가할 만한 비즈니스 로직
- 일정 충돌 자동 탐지와 경고: 같은 날짜의 시간 겹침을 저장 전후로 모두 검출해 조정 필요 상태를 보여준다.
- 업무일지 작성 상태 표시: 날짜별로 기록 여부를 캘린더와 요약 지표에 반영한다.
- 주간보고 자동 정리: 업무일지의 핵심 요약, 이슈, 다음 액션을 주간 단위로 모아 정리한다.
- 기본값 자동 채움: 새 일정 생성 시 선택일과 최근 입력값을 일부 자동으로 채워 등록 속도를 높인다.
- 일정 알림 정책: 일정별 알림 시점을 설정하고, 시작 전 브라우저 알림을 보낸다.
- 상태 기반 강조 정책: 예정, 완료, 조정 필요 같은 상태를 색상과 배지로 구분해 의사결정을 돕는다.
- 일정 밀도 힌트: 하루 일정이 많을수록 더보기 또는 기록 우선 안내를 제공한다.

## 제외 범위
- 팀 부하 관리
- 협업 역할/권한 관리
- 이메일 알림 발송
- 외부 캘린더 양방향 연동
- 반복 일정 고급 규칙
- AI 작성 보조

## 외부 연동 후보
- 공휴일 / 휴일 API: 즉시 적용 후보다. 일정과 마감이 휴일과 겹치는지 빠르게 파악할 수 있다.
- Google Calendar 연동: 차기 적용 우선순위가 높다. 외부 일정 참고나 가져오기 용도로 유용하다.
- Apple Calendar / iCloud Calendar 연동: 개인 캘린더 앱 성격과 잘 맞는 차기 후보다.
- 이메일 알림 연동: 차기 적용 후보다. 중요한 일정이나 주간보고 제출 알림에 활용할 수 있다.

## 우선순위 제안
- 1순위: 업무일지 작성, 주간보고 자동 요약, 브라우저 알림
- 2순위: 일정 충돌 자동 탐지, 기본값 자동 채움, 공휴일 API
- 3순위: Google Calendar, Apple Calendar, 이메일 알림

## 완료 기준
- 사용자는 앱 진입 후 달력을 즉시 메인으로 인식해야 한다.
- 날짜 선택 후 일정과 업무일지를 같은 흐름에서 확인할 수 있어야 한다.
- 사용자는 업무일지를 빠르게 작성하고 저장할 수 있어야 한다.
- 주간보고는 주 단위 기록을 자동으로 묶어 보여줘야 한다.
- 중요한 일정은 브라우저 알림으로 미리 확인할 수 있어야 한다.
- 모바일에서도 달력과 주요 CTA가 읽혀야 한다.
