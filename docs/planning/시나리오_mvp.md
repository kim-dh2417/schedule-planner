# 업무일지 기반 주간보고 캘린더 MVP 시나리오

## 목적

이 문서는 주요 개인 사용 흐름을 단계별 시나리오로 정리한다.

## 시나리오

### 1. 하루가 끝날 때 업무일지를 작성하는 흐름

1. 사용자가 달력에서 오늘 날짜를 선택한다.
2. 선택일 드로어에서 오늘 일정과 업무일지 영역을 함께 확인한다.
3. `업무일지 작성` 버튼을 눌러 모달을 연다.
4. 한 줄 요약, 완료한 일, 이슈, 다음 액션을 입력한다.
5. 저장 후 선택한 날짜에 기록 완료 상태가 반영되는지 확인한다.

### 2. 새 일정을 등록하고 알림을 설정하는 흐름

1. 사용자가 `일정 추가` 버튼을 누른다.
2. 제목, 날짜, 시간, 유형을 입력한다.
3. 알림 시점을 선택한다.
4. 저장 버튼을 누른다.
5. 저장 완료 후 달력과 선택일 상세를 다시 확인한다.

### 3. 주간보고를 확인하는 흐름

1. 사용자가 주간보고 버튼을 누른다.
2. 선택한 날짜가 포함된 주간 범위가 계산된다.
3. 해당 주의 업무일지와 일정이 자동으로 묶인다.
4. 핵심 요약, 일자별 기록, 이슈, 다음 액션을 확인한다.
5. 필요하면 주간보고 텍스트를 복사한다.

### 4. 일정 알림을 받는 흐름

1. 사용자가 브라우저 알림을 허용한다.
2. 일정 생성 또는 수정 시 알림 시점을 설정한다.
3. 일정 시작 전 지정한 시점에 PC 알림이 뜬다.
4. 사용자는 알림을 보고 일정 준비를 한다.
5. 알림 권한이 차단된 경우 설정 안내 문구를 확인한다.
