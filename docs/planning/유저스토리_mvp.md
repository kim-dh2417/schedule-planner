# 업무일지 기반 주간보고 캘린더 MVP 유저 스토리

## 목적

이 문서는 MVP에서 해결해야 할 개인 사용자 가치와 수용 기준을 유저 스토리 형태로 정리한다.

## 유저 스토리

### 1. 그날의 업무 기록

- 역할: 직장인
- 목표: 그날 한 일을 날짜 기준으로 바로 기록하고 싶다
- 가치: 나중에 주간보고를 쓸 때 기억에 의존하지 않아도 된다
- Acceptance Criteria:
- 특정 날짜에서 업무일지를 작성할 수 있다
- 한 줄 요약, 완료한 일, 이슈, 다음 액션을 저장할 수 있다
- 저장 후 해당 날짜에 기록 여부가 반영된다

### 2. 일정과 기록을 함께 확인

- 역할: 개인 사용자
- 목표: 일정과 업무 기록을 같은 화면 흐름에서 확인하고 싶다
- 가치: 하루 흐름과 실제 진행 상황을 같이 파악할 수 있다
- Acceptance Criteria:
- 달력에서 날짜를 선택하면 일정과 업무일지가 함께 보인다
- 일정이 없거나 업무일지가 없으면 각각 빈 상태 안내가 보인다
- 일정 수정과 업무일지 수정이 빠르게 가능하다

### 3. 주간보고 자동 정리

- 역할: 프리랜서 또는 실무자
- 목표: 일주일간 쌓인 기록으로 주간보고 초안을 빠르게 보고 싶다
- 가치: 메모를 다시 모으는 시간을 줄일 수 있다
- Acceptance Criteria:
- 주간 단위로 기록을 묶은 요약을 볼 수 있다
- 핵심 요약, 이슈, 다음 액션이 자동으로 정리된다
- 필요하면 텍스트를 복사해 외부에 붙여넣을 수 있다

### 4. 일정 알림 받기

- 역할: 개인 사용자
- 목표: 중요한 일정 전에 PC 알림을 받고 싶다
- 가치: 미팅과 마감을 놓치지 않을 수 있다
- Acceptance Criteria:
- 일정별 알림 시점을 설정할 수 있다
- 브라우저 권한 허용 후 PC 알림을 받을 수 있다
- 권한이 없으면 안내 문구가 보인다
