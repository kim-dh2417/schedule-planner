## 기능 목록

### 1. 월간 달력
- 입력: 날짜 선택, 월간 일정 데이터, 업무일지 작성 여부
- 출력: 선택일 상태, 이벤트 배지, 오늘 표시, 기록 여부, 충돌 표시
- 상태: 기본, 오늘, 선택됨, 비활성, 일정 많음, 충돌, 기록 완료
- 예외: 일정과 업무일지가 모두 없는 날짜는 빈 상태를 보여준다.

### 2. 선택일 드로어
- 입력: 선택한 날짜, 해당 날짜의 일정 목록, 업무일지 데이터
- 출력: 선택일 일정 목록, 일정 상세, 업무일지 요약, 충돌 경고
- 상태: 기본, 비어 있음, 충돌, 선택 일정 강조, 업무일지 있음
- 예외: 일정과 업무일지가 모두 없으면 빈 상태 문구와 CTA를 보여준다.

### 3. 일정 추가/수정 모달
- 입력: 제목, 날짜, 시작 시간, 종료 시간, 유형, 상태, 알림 시점, 메모
- 출력: 일정 생성 또는 기존 일정 갱신 메시지
- 상태: 작성 중, 저장 성공, 저장 실패, 검증 오류
- 예외: 필수값이 없으면 저장을 막고 오류 메시지를 보여준다.

### 4. 업무일지 작성 모달
- 입력: 한 줄 요약, 완료한 일, 이슈, 다음 액션
- 출력: 날짜별 업무일지 저장 결과
- 상태: 작성 중, 저장 성공, 미작성, 수정
- 예외: 모든 항목이 비어 있으면 저장을 막고 작성 유도 문구를 보여준다.

### 5. 주간보고 자동 요약
- 입력: 주간 범위의 일정 데이터, 업무일지 데이터
- 출력: 주간 핵심 요약, 일자별 기록 목록, 이슈, 다음 액션
- 상태: 기본, 기록 부족, 기록 충분
- 예외: 주간 기록이 부족하면 빈 상태와 작성 유도 메시지를 보여준다.

### 6. 브라우저 알림
- 입력: 일정 시작 시각, 알림 시점, 브라우저 알림 권한
- 출력: 일정 시작 전 PC 알림
- 상태: 권한 필요, 활성화, 비활성화, 차단됨
- 예외: 브라우저 권한이 없으면 설정 유도 메시지를 보여준다.

### 7. 충돌 자동 탐지
- 입력: 시작 시간, 종료 시간, 같은 날짜의 기존 일정 목록
- 출력: 충돌 여부, 조정 필요 배지, 저장 전 경고
- 상태: 정상, 충돌, 저장 가능
- 예외: 일정이 겹쳐도 저장은 가능하되 사용자에게 명확한 경고를 보여준다.

### 8. 기본값 자동 채움
- 입력: 선택일, 최근 사용한 일정 유형, 마지막 사용 알림 설정
- 출력: 새 일정 초안의 기본값
- 상태: 기본, 최근값 반영, 초기값
- 예외: 최근값이 없으면 기본 템플릿을 사용한다.

## 공통 규칙
- 같은 날짜에 일정이 2개 이상 겹치면 충돌 상태로 표시한다.
- 선택된 일정은 드로어와 모달에서 강조한다.
- 업무일지는 날짜 단위로 저장하고 주간보고 생성의 기준 데이터로 사용한다.
- 주간보고는 기록을 자동 정리하되 사용자가 그대로 복사하거나 수정할 수 있어야 한다.
- 브라우저 알림은 페이지가 열려 있고 권한이 허용된 경우에만 동작한다.
