# 업무일지 기반 주간보고 캘린더 MVP 요구사항 정의서

## 목적

이 문서는 업무일지 기반 주간보고 캘린더 MVP의 목표, 범위, 대상 사용자, 완료 기준을 정리한 요구사항 정의서이다. 이후 기능 명세, 화면 설계, 개발, QA 문서의 기준점으로 사용한다.

## 목표

- 일정과 그날의 업무 기록을 같은 화면 흐름에서 관리한다.
- 업무일지를 날짜 기준으로 누적해 주간보고 작성을 쉽게 만든다.
- 중요한 일정은 시작 전에 브라우저 알림으로 챙길 수 있게 한다.

## 대상 사용자

- 일일 업무일지를 남겨야 하는 직장인
- 프로젝트 진행 상황을 스스로 정리하는 프리랜서
- 주간보고나 회고를 수동으로 정리하는 개인 사용자

## 문제 정의

- 그날 한 일을 제때 기록하지 못해 주간보고를 쓸 때 기억에 의존한다.
- 일정과 업무 메모가 분리돼 하루 흐름과 성과를 함께 보기 어렵다.
- 주간보고를 만들 때 여러 도구를 다시 뒤져야 한다.
- 중요한 일정 알림을 놓쳐 마감이나 미팅 준비가 늦어진다.

## 범위

### 포함

- 월간 캘린더
- 선택일 상세 드로어
- 일정 등록, 수정, 삭제
- 날짜별 업무일지 작성
- 주간보고 자동 요약
- 브라우저/PC 알림
- 일정 충돌 경고

### 제외

- 팀 부하 표시
- 팀 협업용 역할/권한
- 이메일 알림 발송
- 외부 캘린더 양방향 연동
- 반복 일정 고급 설정
- AI 자동 작성

## 완료 기준

- 사용자가 첫 화면에서 이번 달 일정 흐름과 오늘 기록 상태를 확인할 수 있다.
- 사용자가 특정 날짜에 일정과 업무일지를 함께 확인할 수 있다.
- 업무일지 저장 후 달력과 선택일 상세가 같은 기준으로 갱신된다.
- 주간보고 모달에서 한 주의 기록 요약을 바로 확인할 수 있다.
- 브라우저 알림 허용 후 중요한 일정 리마인드를 받을 수 있다.
