## 목적
메인 화면의 정보 밀도를 낮추고, 월간 캘린더를 중심으로 사용자 행동을 설계한다. 일정 상세와 편집은 화면 안에 계속 펼치지 않고 드로어와 모달로 분리한다.

## 1차 구조
### Desktop
- 상단 Hero
- 얇은 KPI 바
- 메인 월간 캘린더
- 우측 선택일 드로어
- 필요 시 오버레이 모달

### Mobile
- 상단 축약 헤더
- KPI 축약 띠
- 월간 캘린더
- 하단에서 올라오는 바텀시트
- 일정 추가 모달

## 섹션 배치
### 상단
- 앱 타이틀과 이번 달 표시
- 주요 CTA 1개: `새 일정 작성`

### 중단
- 월간 캘린더 7열 그리드
- 날짜 셀은 최대 2개의 이벤트 칩 표시
- 오늘 날짜, 선택 날짜, 충돌 날짜를 별도 처리

### 보조 레이어
- 선택일 드로어
- 일정 추가/수정 모달
- Team Pulse 팝업 또는 탭
- Focus Blocks 팝업 또는 탭

## 데스크톱 와이어
```text
┌───────────────────────────────────────────────────────────────────────────┐
│ Hero / Month title / CTA                                                  │
├───────────────────────────────────────────────────────────────────────────┤
│ KPI strip                                                                 │
├───────────────────────────────────────────────┬───────────────────────────┤
│ Monthly calendar                              │ Selected day drawer       │
│ 7x5 grid                                       │ - date                    │
│ - today state                                  │ - agenda list             │
│ - conflict state                               │ - detail card             │
│ - event chips                                  │ - edit/delete actions     │
└───────────────────────────────────────────────┴───────────────────────────┘
```

```text
├───────────────────────────────┤
│ KPI strip                     │
├───────────────────────────────┤

├───────────────────────────────┤

```

## 상태
- 빈 날짜: 빈 상태 카드 노출
- 이벤트 많은 날짜: `+n more` 표시
- 충돌 날짜: 셀 테두리와 태그 강조
- 선택 날짜: 드로어 자동 오픈
