## 목적

이 문서는 일정관리 앱에서 재사용할 시각 규칙과 컴포넌트 기준을 정의한다. 대시보드, 추후 로그인, 상세, 설정 화면에서도 일관되게 사용할 수 있도록 기본 토큰을 정리한다.

## 색상 토큰

- `--color-bg`: 전체 배경
- `--color-surface`: 카드 배경
- `--color-surface-strong`: 강조 카드 배경
- `--color-text`: 본문 텍스트
- `--color-text-muted`: 보조 텍스트
- `--color-border`: 경계선
- `--color-mint`: 일정/긍정 상태
- `--color-amber`: 주의/집중 상태
- `--color-coral`: 충돌/경고 상태
- `--color-sky`: 진행/정보 상태

## 타이포 체계

- 제목 1: Hero, 페이지 타이틀
- 제목 2: 패널 타이틀
- 제목 3: 섹션 소제목
- 본문: 설명, 메타, 상태 문구
- 캡션: 날짜, 배지, 보조 설명

## 공간 체계

- `xs`: 4px
- `sm`: 8px
- `md`: 12px
- `lg`: 16px
- `xl`: 24px
- `2xl`: 32px

## 라운드와 섀도우

- 카드 기본 radius는 20px 이상을 사용한다.
- Hero와 강조 패널은 더 큰 radius를 사용한다.
- 섀도우는 깊이를 주되, 떠 보이는 느낌이 지나치지 않게 제한한다.

## 버튼 규칙

- Primary 버튼은 가장 중요한 단일 행동에만 사용한다.
- Secondary 버튼은 보조 행동에 사용한다.
- Ghost 버튼은 패널 상단 보조 액션에 사용한다.
- 버튼 높이는 일정하게 유지한다.

## 칩 규칙

- 상태 칩은 짧고 읽기 쉬운 텍스트를 사용한다.
- 활성 상태는 배경색과 텍스트색을 함께 바꾼다.
- 선택 상태는 칩만으로 아니라 주변 컨텍스트와 함께 표현한다.

## 패널 규칙

- 패널은 공통 헤더, 본문, 보조 액션 구조를 따른다.
- 패널 제목은 짧고 명확해야 한다.
- 패널 간 간격은 충분히 확보한다.

## 입력 규칙

- 입력 셀은 실제 폼으로 바뀌어도 형태가 유지되어야 한다.
- 입력과 설명은 같은 상자 안에서 시각적으로 구분한다.
- 비활성 상태는 명확하게 낮은 대비로 표현한다.

## 상태 규칙

- 기본: 일반 정보 표시
- 선택: 사용자 선택이 반영된 상태
- 비활성: 사용 불가 또는 범위 밖 상태
- 경고: 일정 충돌, 과부하, 주의 필요 상태
- 로딩: 데이터가 아직 준비되지 않은 상태

## 재사용 원칙

- 색상과 간격은 토큰만 사용하고 직접 숫자를 줄이지 않는다.
- 캘린더, 카드, 패널, 칩은 모든 화면에서 동일 규칙을 따른다.
- 새 컴포넌트가 필요하면 먼저 기존 패턴으로 대체 가능한지 검토한다.
