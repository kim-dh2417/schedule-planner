## 목적
달력 중심 화면에서 사용자가 `언제`, `무엇을`, `얼마나`, `누구와`를 즉시 판단하고, 세부 동작은 드로어와 모달에서 처리하도록 상호작용을 정의한다.

## 핵심 상호작용
### 1. 날짜 선택
- 달력 셀을 클릭하면 선택 상태가 바뀐다.
- 선택일 정보는 우측 드로어로 열린다.
- 드로어 상단에는 날짜, 일정 개수, 충돌 여부를 노출한다.
- 동일 날짜를 다시 클릭해도 드로어는 유지하되 선택 상태만 갱신한다.

### 2. 일정 상세 보기
- 드로어 안의 일정 카드를 클릭하면 상세 카드가 활성화된다.
- 상세 카드에는 시간, 참여자, 메모, 상태가 보인다.
- 충돌 일정이면 경고 태그가 함께 노출된다.

### 3. 일정 추가
- `새 일정 작성` 버튼 또는 상단 CTA로 모달을 연다.
- 모달은 추가 모드에서 빈 폼을 보여준다.
- 저장 후 캘린더와 선택일 드로어가 함께 갱신된다.

### 4. 일정 수정
- 드로어에서 특정 일정을 클릭하면 수정 모드로 전환된다.
- 폼에는 기존 값이 선반영된다.
- 저장 시 동일 ID의 일정이 교체된다.

### 5. 일정 삭제
- 상세 카드에서 삭제 버튼을 누르면 확인 액션 후 제거한다.
- 삭제 후 선택일이 비어 있으면 빈 상태 카드가 열린다.

### 6. Team Pulse / Focus Blocks
- 상단 액션 또는 탭으로 진입한다.
- 기본 화면에서는 노출하지 않고 보조 레이어에서만 연다.
- 모바일에서는 완전 분리된 하단 시트로 전환한다.

## 상태 전환
- 기본 상태: 달력만 보이고 드로어는 닫힘
- 선택 상태: 드로어 오픈
- 추가 상태: 일정 모달 오픈
- 편집 상태: 일정 모달에 기존 값 주입
- 빈 상태: 선택일 일정이 없을 때 안내 카드
- 충돌 상태: 셀/드로어/태그에 경고 스타일 적용

## 피드백 규칙
- 저장 성공: 짧은 확인 문구 노출
- 저장 실패: 폼 상단에 바로 이유 노출
- 충돌 발생: 빨간색 경고 태그와 짧은 설명 노출
- 비어 있음: 행동 유도형 문구 노출

## 마이크로 인터랙션
- 달력 셀 hover 시 가벼운 상승 효과
- 선택된 날짜는 색 대비와 테두리로 강조
- 모달 오픈 시 배경은 dim 처리
- 드로어는 우측에서 슬라이드 인
